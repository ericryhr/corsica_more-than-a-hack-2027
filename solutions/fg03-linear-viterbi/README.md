# fg03-linear-viterbi

Linear (logistic) per-frame evidence for owner and dead ball from geometry, ball and Smart Tagging features with time windows, decoded with a 3-state Viterbi.

Vendored here because er03-windowed-viterbi imports this folder's `src/` code (see its `src/peers.py`). See the top-level README for what the presented solution is and how to reproduce it.
